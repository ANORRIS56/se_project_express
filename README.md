# WTWR (What To Wear?)

## Description

WTWR is a full-stack weather-aware wardrobe management application that helps users organize and manage clothing items based on current weather conditions. By combining real-time weather data with a personalized clothing collection, WTWR provides an interactive experience where users can browse, save, and manage apparel suitable for different temperatures.

The application features secure user authentication with JSON Web Tokens (JWT), protected API routes, profile customization, and persistent data storage using MongoDB. Users can create accounts, update profile information, add new clothing items, remove items they own, and maintain a personalized digital wardrobe from any device.
