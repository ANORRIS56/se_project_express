# WTWR (What to Wear?): Back End

## Description

This project is the back-end server for the WTWR (What to Wear?) application. It provides API endpoints for managing users and clothing items. The server handles creating, retrieving, updating, and deleting data stored in a MongoDB database.

## Functionality

- Create and retrieve users
- Create, retrieve, and delete clothing items
- Like and unlike clothing items
- Store data using MongoDB
- Handle errors with appropriate status codes

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- ESLint (Airbnb style guide)

## Running the Project

Run the development server:

```bash
npm run dev
```
